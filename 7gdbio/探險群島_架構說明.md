# 生物探險群島：架構說明（2026-10-29）

取代舊的「一章一個 HTML 複製模板」做法（chapter5 模板 v4.1）。舊指引中 CHAPTER_DATA、themeColors、15 處寫死位置等規則，不適用於新架構。

## 結構
- `index.html`（由 `src/page.html` + `src/build.sh` 產生）、`engine/`：地圖、闖關、iPad 觸控、證書、進度。做章節時不修改。
- `data/curriculum.js`：七上、七下共 12 座島（章），每章 `data: null` 或 `data: 'data/{章id}.js'`。storageKey：`biology_grade7_world_v1`。
- `data/{章id}.js`：`QuizWorld.registerChapter({ id, sections: [{ id, title, levels: [...] }] })`。節數、關卡數由內容決定。
- 章 id：七上 `7a-1`…`7a-5`、跨科 `7a-x`；七下 `7b-1`…`7b-5`、跨科 `7b-x`。
- `tools/validate.js`：`node tools/validate.js [data/xxx.js]`。
- Antigravity 規則：專案最上層 `AGENTS.md`（免 frontmatter，永遠生效）。
- `/new-chapter`：`.agents/skills/new-chapter/SKILL.md`（frontmatter 需 name、description）。三個教師確認點。
  - 註：Antigravity 舊版 workflows（`.agent/workflows/`）自 2026-10-19 起不再支援，已改為 skill；`.agent/rules/*.md` 缺 frontmatter 的 `trigger` 會被忽略，所以改用 AGENTS.md。

## 題型
- `classification`：zones（2–4，`{id,title,icon}`）＋ items（`{text, zone, explain?}`），每區至少一張正確卡。
- `order`：items 依正確順序（3–8），遊戲自動打亂。
- `formula`：left、right[]、ops?（預設 ×）、ordered?（有 ÷/− 時 true）、distractors?。
- 每關可加 `summary`（過關重點），卡片可加 `explain`（顯示在錯誤記錄與證書）。

## 遊戲規則
- 章間自由進入，章內小節依序解鎖；完成整章插旗、解鎖徽章。
- 星等：每節答錯 0 次 3 星、1–2 次 2 星、3 次以上 1 星；保留最佳星數。
- 證書：島嶼認證書（每節星等、用時、完成時間、錯誤記錄＋正確答案）、總任務報告。
- 進度存在瀏覽器 localStorage；進度碼可匯出、匯入換裝置。

## 防抄襲追蹤
- 探險編號（每份進度一組，隨進度碼移動）、改名紀錄、匯入紀錄、每節完成時間，全部印在證書上。
- 有改名或匯入時，證書的身分紀錄框變紅。小節 id 上線後不可更改（進度以它為鍵）。

## iPad 觸控
- 觸控用 Touch Events，在 touchstart 立即 preventDefault（passive:false，沿用 v4.1 作法）；滑鼠用 Pointer Events。也支援「點卡片再點目標」。

## 部署與多科目
- GitHub 儲存庫 `textbookisland`（公開，免費帳號私人庫不能用 Pages），各科一個子資料夾：生物 `7gdbio`，網址 `https://帳號.github.io/textbookisland/7gdbio/`。
- 最上層 `.gitignore`：`**/materials/`、`**/work/`、`*.pdf`（課本有版權）。
- 每科在 Antigravity 開獨立專案，指向該科資料夾；每科 storageKey 必須不同（同一 github.io 網域共用瀏覽器儲存空間）。
- 教材放 `materials/7a/`、`materials/7b/`。
- 狀態：七上第 1 章示範題教師已確認可用；基本測試已通過（2026-10-29）。下一步：第 2 章「養分」（7a-2）。
