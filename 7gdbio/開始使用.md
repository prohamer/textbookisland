# 生物探險群島：使用說明

學生打開網址，看到七上、七下兩張海圖，每一章是一座島。依序完成島上的小節就能插旗、解鎖徽章，並領取該島認證書；選單裡有總任務報告。

---

## 一、資料夾裡有什麼

```
quiz-world/
├── index.html            ← 網站入口（學生打開的就是它）
├── engine/               ← 遊戲引擎：地圖、拖拉、iPad 觸控、證書、進度（不需要改）
├── data/
│   ├── curriculum.js     ← 地圖結構：七上七下各章、目錄小節、圖示、顏色
│   └── 7a-1.js           ← 七上第 1 章題目（示範，請對照課本確認）
├── tools/validate.js     ← 題目檢查腳本
├── .agent/               ← 給 Antigravity 的規則與 /new-chapter 流程
├── materials/            ← 放教材 PDF（不會上傳給學生也沒關係）
├── work/                 ← 代理寫的分析稿、題目設計稿
└── src/                  ← 產生 index.html 用的原始檔（不需要改）
```

**之後每做一章，只會多一個 `data/xxx.js`，再把 curriculum.js 那一章的 `data: null` 改成檔名。**引擎完全不用動。

---

## 二、在 Antigravity 使用

1. 把 `D:\Biotextbook` 裡原本的 quiz-workspace 內容移走（舊版不再需要）。
2. 把這個資料夾**裡面的所有東西**（包含隱藏的 `.agent`）放到 `D:\Biotextbook` 最上層。
3. 在 Antigravity 開啟 Biotextbook 專案，到 **Customizations** 確認：
   - Rules：`quiz-world`
   - Workflows：`new-chapter`
4. 把教材 PDF 放進 `materials/`。
5. 開新對話，輸入：

```
/new-chapter
做七上第 2 章「養分」（7a-2），教材是 materials/生物7上_第2章.pdf
```

代理會依序停下來三次讓你確認：分析結果 → 每一節的題目 → 寫入前。

## 三、放上網路給學生用（GitHub Pages，免費）

只需要做一次。之後新增章節，上傳新檔案就會自動更新。

### 1. 建立帳號與儲存庫
1. 到 github.com 註冊帳號（可用學校信箱）。
2. 右上角 **+** → **New repository**。
3. Repository name 填英文，例如 `bio-island`；選 **Public**；按 **Create repository**。

### 2. 上傳檔案
1. 在新儲存庫頁面點 **uploading an existing file**（或 **Add file → Upload files**）。
2. 把 `index.html`、`engine` 資料夾、`data` 資料夾拖進去。
   - `materials`、`work`、`.agent`、`tools`、`src` 不需要上傳。
3. 按 **Commit changes**。

### 3. 開啟網站
1. 儲存庫上方 **Settings** → 左側 **Pages**。
2. Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾 **/(root)**，按 **Save**。
3. 等 1–2 分鐘，頁面上方會出現網址，格式是：
   `https://你的帳號.github.io/bio-island/`
4. 把網址做成 QR code 貼在教室，學生用 iPad 掃描即可。

> 建議學生在 Safari 開啟後，按分享 →「加入主畫面」，之後就像 App 一樣從主畫面打開，進度也比較不會被清掉。

### 4. 之後新增章節
上傳新的 `data/xxx.js` 和更新後的 `data/curriculum.js`（同名檔案會被覆蓋），學生重新整理就會看到新的島。
如果代理已經幫你設定好 git，也可以請它「推送到 GitHub」。

## 四、學生進度要知道的事

- 進度存在**每台 iPad 的瀏覽器**裡，沒有帳號、不會上傳到任何地方。
- 換裝置或要清除瀏覽器資料前，請學生到 **選單 → 進度碼 → 匯出**，把進度碼傳給自己（例如 Google Classroom 私人留言），在新裝置 **匯入** 即可還原。
- 學生清除 Safari 的「網站資料」會讓進度消失。
- 已經開始使用後，**不要更改資料檔裡的小節 id**，否則該節進度會不見（題目內容可以改）。

## 五、核對學生繳交的證書（防抄襲）

純前端網頁無法阻止學生複製別人的進度，但每張證書都會留下痕跡，看三個地方：

| 看哪裡 | 正常 | 可疑 |
|---|---|---|
| **身分紀錄**（證書下方框） | 只有一行「首次登記為 …」 | 框變紅、標示「有修改或匯入紀錄」，列出改名或匯入進度碼的時間與前後姓名 |
| **探險編號**（證書右下角） | 每位學生不同 | 兩位學生的編號相同，表示是同一份進度 |
| **完成時間**（表格最右欄） | 分散在不同時間 | 和另一位學生的時間一模一樣 |

學生合理換裝置時，也會出現「匯入進度碼」紀錄，但碼內姓名就是自己，不會有改名紀錄。

## 六、證書

- **島嶼認證書**：完成一座島所有小節後領取，含每節星等、用時、錯誤記錄與正確答案。
- **總任務報告**：選單裡隨時可產生，列出所有島的完成狀況與徽章。
- 按「產生圖片」後，iPad 長按圖片即可存到照片，再上傳到 Classroom 等平台繳交。

## 七、星星規則

每一節：全程沒答錯 3 顆星；答錯 1–2 次 2 顆星；3 次以上 1 顆星。重新挑戰會保留最佳星數，證書上的錯誤記錄則顯示最近一次挑戰。

## 八、自己檢查題目

在終端機（Antigravity 裡也可以）於專案資料夾執行：

```
node tools/validate.js
```

會列出所有章節的問題，例如卡片的分類寫錯、某個分類區沒有正確卡片、小節 id 重複等。
