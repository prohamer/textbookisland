# 新增一座城堡（一章）

依照專案最上層 `AGENTS.md` 的規則執行。每個「⏸ 停」都必須等教師回覆後才繼續。

## 步驟 0：確認基本資料

- 要做的是 `data/curriculum.js` 裡哪一座城堡（章 id：`pc0`～`pc18`、`pcx1`、`pcx2`）
- 查 `work/章節對照.md`：這座城堡對應 `materials/` 裡哪個檔案、哪幾頁
- 有沒有想強調或排除的概念
- 這一章的資料檔是否已存在（已存在就是修改，要保留原本的小節 id）

## 步驟 1：教材分析

1. 若還沒有 `work/{章id}_教材.md`，用 Python + pymupdf 把對應頁數的文字抽出來存成這個檔案（只抽需要的頁數，不要整本）。PDF 的頁碼可能和課本印的頁碼差幾頁，抽完先看開頭結尾是否正確。
2. 閱讀教材，參考 curriculum 的目錄小節，決定實際要分幾節（可與目錄不同）。
3. 每節找出 2–4 個適合出題的概念，選擇題型：
   - 有分類標準 → `classification`
   - 有先後順序（實驗步驟、過程、由小到大）→ `order`
   - 有乘除關係的公式 → `formula`
4. 寫入 `work/{章id}_分析.md`：

```
## {章id} 城堡名
- {章id}-1 小節名（N 關）
  - 第1關：概念 → 題型（理由一句）
- …
總關卡數：N
與 curriculum 目錄不同之處：（若有）
```

⏸ **停：請教師確認或調整。**

## 步驟 2：逐節設計題目（一次一節）

寫入 `work/{章id}_題目設計.md`：

```
### {章id}-1 第1關：標題
題型：分類題
說明：請將……分類
分類區：A（⚖️）、B（🌍）
卡片：
- 卡片文字 → A
- 卡片文字 → B（解說：容易錯的原因）
過關重點：一句話
```

公式題寫法：`D = M ÷ V（ordered，干擾項：T）`。

自我檢查：每個分類區都有卡片、沒有爭議卡片、符合教材、字數在限制內、單位符號正確、沒有寫到課本版本、年級或章次。

⏸ **停：請教師確認這一節，確認後才做下一節。**

## 步驟 3：寫入前確認

列出：資料檔名 `data/{章id}.js`、所有小節 id 與標題、總關卡數。

⏸ **停：請教師確認。**

## 步驟 4：寫入

1. 依 `AGENTS.md` 第 5 節的格式建立 `data/{章id}.js`。
2. 在 `data/curriculum.js` 將這一章的 `data: null` 改為 `data: 'data/{章id}.js'`。其他欄位都不要動。

## 步驟 5：檢查與回報

1. `node tools/validate.js data/{章id}.js`，修到 0 個 ❌。
2. 瀏覽器實測（見規則第 6 節）。
3. 回報：驗證結果、實測內容、提醒教師 iPad 實機測試、詢問是否要上傳。
